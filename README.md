- **Background processing:** pause/resume, retries, timeouts, provider circuit breaker, and recovery for stuck or duplicate jobs
- **Security:** JWT + refresh tokens, Google/Facebook sign-in, account lockout, owner-based authorization, rate limiting, security headers, encryption, and audit logs
- **Data:** versioned EF Core migrations, performance indexes, perceptual frame hashing, S3-compatible storage, and retention cleanup
- **Quality:** xUnit, pytest, Vitest, Playwright, health checks, structured logging, and production-oriented error handling
